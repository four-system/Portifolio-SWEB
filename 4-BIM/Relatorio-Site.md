## Introdução

Com o avanço da tecnologia, a utilização de sistemas informatizados tornou-se cada vez mais importante para a organização e administração de empresas. No setor gráfico, o controle de clientes, pedidos, funcionários, produtos, vendas e estoque é fundamental para garantir um bom funcionamento das atividades e melhorar a qualidade dos serviços oferecidos.

Pensando nisso, foi desenvolvido um Sistema de Gerenciamento de uma Gráfica, com o objetivo de facilitar o controle das principais operações realizadas nesse tipo de estabelecimento.

O sistema foi desenvolvido utilizando tecnologias voltadas para aplicações web, permitindo que os funcionários e responsáveis pela administração tenham acesso às funcionalidades de acordo com suas necessidades.

Durante o desenvolvimento, foram trabalhadas diferentes áreas do sistema, incluindo login de funcionários, administração, gerenciamento, vendas, estoque e relatórios. O projeto também envolveu a utilização de ferramentas de Inteligência Artificial como apoio aos estudos, à revisão do código, à correção de erros e ao desenvolvimento visual do site.

## 1. Objetivo do Sistema

O principal objetivo do projeto é desenvolver uma aplicação web capaz de auxiliar na organização e no gerenciamento das atividades de uma gráfica.

O sistema busca centralizar informações e facilitar tarefas que, quando realizadas manualmente, podem exigir mais tempo e aumentar a possibilidade de erros.

### Principais objetivos

- Facilitar o acesso dos funcionários ao sistema.
- Organizar as funcionalidades administrativas.
- Auxiliar no gerenciamento dos funcionários.
- Controlar as vendas realizadas.
- Acompanhar os produtos e o estoque.
- Disponibilizar relatórios para consulta.
- Melhorar a organização das informações da gráfica.

## 2. Desenvolvimento do Projeto

O desenvolvimento foi dividido entre os integrantes do grupo, de maneira que cada participante ficasse responsável por determinadas partes do sistema.

Durante o processo, as telas foram desenvolvidas e integradas, enquanto erros encontrados eram corrigidos e funcionalidades eram finalizadas.

### 2.1 Tela de Login

Foi desenvolvida uma tela de login destinada aos funcionários da gráfica.

Essa funcionalidade tem como finalidade permitir o acesso ao sistema por meio de uma área de autenticação, servindo como ponto de entrada para as demais funcionalidades.

### 2.2 Administração, Gerência e Funcionários

O projeto também possui áreas destinadas à administração e ao gerenciamento da gráfica.

Essas áreas foram desenvolvidas para organizar as funcionalidades administrativas e facilitar o acesso às informações relacionadas ao funcionamento do estabelecimento.

A área de funcionários foi posteriormente finalizada e revisada, incluindo correções de erros encontrados durante o desenvolvimento.

### 2.3 Vendas e Estoque

Foi desenvolvida uma área destinada ao gerenciamento das vendas e do estoque.

Essas funcionalidades têm como objetivo auxiliar no acompanhamento das operações comerciais e na organização dos produtos disponíveis na gráfica.

### 2.4 Relatórios

Foi desenvolvida uma aba de relatórios para reunir informações do sistema e facilitar a consulta dos dados administrativos e comerciais.

Essa parte complementa as funcionalidades de gerenciamento, permitindo uma visão mais organizada das informações registradas.

## 4. Tecnologias e Ferramentas Utilizadas

Durante o desenvolvimento, foram utilizadas ferramentas e tecnologias voltadas à criação de aplicações web.

### PHP

Linguagem utilizada no desenvolvimento das funcionalidades do sistema, permitindo o processamento das informações e a comunicação com o banco de dados.

### MySQL

Sistema de gerenciamento de banco de dados utilizado para armazenar e organizar as informações necessárias ao funcionamento da aplicação.

### HTML

Utilizado para estruturar os elementos e conteúdos das páginas do site.

### CSS

Utilizado para definir a aparência visual das páginas, incluindo cores, posicionamentos, tamanhos e organização dos elementos.

### JavaScript

Pode ser utilizado para adicionar interatividade e comportamentos às páginas da aplicação, conforme a implementação do projeto.

### XAMPP

Ambiente utilizado para executar localmente a aplicação web e disponibilizar os serviços necessários ao desenvolvimento com PHP e MySQL.

O desenvolvimento do Sistema de Gerenciamento de uma Gráfica proporcionou ao grupo a oportunidade de trabalhar com a criação de uma aplicação web voltada para uma situação prática do ambiente empresarial.
