Criptografia no PHP

O que é criptografia?

Criptografia é uma técnica utilizada para proteger informações, transformando os dados de uma forma que dificulta o acesso de pessoas não autorizadas.

No PHP existem diferentes funções relacionadas à segurança, como funções de hash, criptografia e codificação. Cada uma possui uma finalidade diferente.
